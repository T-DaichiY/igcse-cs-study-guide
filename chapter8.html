8.1.1–8.1.3 Variables, types & I/O

storing data

8.1.1 Variables and Constants

TermDefinition
VariableA named data store containing a value that may change during execution
ConstantA named data store containing a value that does not change during execution
IdentifierThe meaningful name given to a variable, constant, array, procedure or function
DeclarationStating a name and (usually) a data type before the identifier is used
DECLARE FirstVar : INTEGER ← explicit: the type is stated CONSTANT PI ← 3.142 ← implicit: the type comes from the value

Explicit declaration states the data type; implicit declaration lets the language work it out from the assigned value. Python has no declaration statement at all and does not distinguish constants — programmers signal them with ALL-CAPITAL names. Java uses final; Visual Basic uses Dim and Const.

📘 Worked Example — Cylinder Volume

π never changes → CONSTANT PI ← 3.142. Radius and Length are typed in each run → variables. Volume changes with the inputs → also a variable.

💡 Meaningful Identifiers Rule.

Name things after what they store — Total, Counter, Radius — never single letters. This is expected in every pseudocode answer, not just maintainability questions.

8.1.2 The Five Basic Data Types

TypeDefinitionExample
INTEGERA positive or negative whole number, usable with mathematical operators25
REALA positive or negative number with a fractional part25.0
CHARA single character'F'
STRINGSeveral characters; may be empty; letters, digits or symbols"Emma"
BOOLEANOnly two values: TRUE or FALSETRUE
⚠️ Common Mistake — "25" Is Not 25.

A number stored as a string cannot be used in a calculation, however much it looks like a digit. It must be cast first (Python: int(), float()). All inputs default to strings, so an input needing arithmetic always needs casting.

📘 Real Exam Error — June 2025 Paper 22 Q5

Line 01: DECLARE Names : ARRAY[1:500] OF REAL → should be OF STRING. A person's name is text, not a number. Write out the whole corrected line — "change REAL to STRING" does not score; the mark is for the exact corrected statement.

8.1.3 Input and Output

Every INPUT needs a prompt saying what to enter, and every OUTPUT needs a message saying what the value is. Parts of an output are joined by a separator: a comma in Python, & in Visual Basic, + in Java.

OUTPUT "Please enter the radius of the cylinder " INPUT Radius Volume ← Radius * Radius * Length * PI OUTPUT "Volume of the cylinder is ", Volume
⚠️ Real Exam Error — Outputting the Wrong Thing.

Line 20: OUTPUT "The shortest height is ", Heights → outputs the whole array. It should be Shortest (or Heights[Index]). Always output the specific variable holding the required result.

8.1.4 Sequence, selection & iteration

control structures
The three loops

8.1.4(a) Sequence — Order Changes Everything

📘 Worked Example — Two Lines Swapped, Three Wrong Answers

A REPEAT loop totals marks until the sentinel 999 is entered. In the broken version the sentinel is added to Total before the loop tests for it, and Counter increments after the test — traced with 25, 27, 23, 999 it gives Total = 1074, Average = 358, Counter = 4.

Corrected: Counter ← -1 REPEAT Total ← Total + Mark ← add BEFORE the next input INPUT Mark Counter ← Counter + 1 UNTIL Mark = 999 Average ← Total / Counter ← calculated ONCE, outside the loop

Same data now gives Total = 75, Average = 25, Counter = 3. Every individual line was already "correct" — only the order was wrong.

💡 Sequence-Checking Rule.

When debugging, check not just what a line does but where it sits relative to the condition test — before or after, inside or outside the loop. And check any variable used in a calculation was given a value earlier.

8.1.4(b) Selection — IF and CASE

IF Age > 17 THEN OUTPUT "You are an adult" ELSE OUTPUT "You are a child" ENDIF CASE OF OpValue "+" : Answer ← Number1 + Number2 "-" : Answer ← Number1 - Number2 OTHERWISE OUTPUT "Please enter a valid choice" ENDCASE
IF … THEN … ELSECASE OF … ENDCASE

In Pythonif / elseNo native CASE — an elif chain

8.1.4(c) Iteration — The Three Loops

Loop typePseudocodeKey property
Count-controlledFOR … TO … NEXTRuns a set, known number of times
Pre-conditionWHILE … DO … ENDWHILETested before each pass — may run zero times
Post-conditionREPEAT … UNTILTested after each pass — always runs at least once
⚠️ Exam Tip — Get the Exit Condition Right.

A WHILE loop stops as soon as its condition becomes false; a REPEAT loop stops as soon as its condition becomes true. Confusing the two gives a trace table with one row too many or too few.

Examiner report on the flowchart question: candidates who "were consistent with their use of the same variables throughout achieved the highest marks" — never switch variable names partway through.

8.1.4 Totals, strings & operators

common operations

8.1.4(d) Totalling and Counting

Total ← 0 ← initialise BEFORE the loop Counter ← 0 Total ← Total + Value ← total on BOTH sides Counter ← Counter + 1
⚠️ Two Real Exam Errors — June 2025 Paper 22 Q5.
  • Line 09: Total ← 100 → should be Total ← 0. A total must start at zero.
  • Line 13: Total ← Counter + Heights[Counter] → should be Total ← Total + Heights[Counter]. The accumulator must appear on both sides — using the loop counter instead breaks the pattern entirely.

Totalling and counting are almost always tested together, with a termination condition based on the count (e.g. "Count = 50").

8.1.4(e) String Handling

MethodDoesExample
LENGTHNumber of characters, spaces includedLENGTH("Computer Science") = 16
SUBSTRINGExtracts part of a stringSUBSTRING("Computer Science", 10, 7) = "Science"
UCASEConverts to uppercase"COMPUTER SCIENCE"
LCASEConverts to lowercase"computer science"
⚠️ Common Mistake — Where Position 1 Is.

Pseudocode strings start at position 1. Python, Visual Basic and Java all start at 0. A substring correct in pseudocode is off by one if translated straight into code.

Pseudocode SUBSTRING(str, start, length) takes a length as its third parameter. Java's substring(9,17) takes an end position. Different conventions — check which one the question uses.

📘 Real Exam Question — Paper 22 Q6(c), the palindrome checker [3]

"Explain how the algorithm knows when all the letters have been checked." Three mark points:

  • Two indexes mark the start (V1) and the end (V2) of the word.
  • After each check V1 is incremented and V2 is decremented.
  • When the indexes meet or cross (V1 = V2, or V1 > V2), the whole word has been checked.

Note from Paper 21: a candidate who answered an explain question with pseudocode alone scored nothing. Explain means write prose.

8.1.4(f) Operators

ArithmeticRelationalLogical
+ − * / ^ MOD DIV= < <= > >= <>AND OR NOT
⚠️ Common Mistake — One Equals Sign.

Python and Java use == to test equality; a single = is assignment. Only pseudocode and Visual Basic compare with a single =. Pseudocode's "not equal" is <>; Python and Java use !=.

📘 Worked Example — Combining Operator Types
IF Value <= -20 OR Value >= 50 → reject: outside the allowed range IF Value > 0 AND Value < 100 → accept: strictly inside the range

Each side is a relational comparison; the logical operator joins them.

8.1.5–8.1.8 Nesting, subroutines & libraries

structured programming
Calling a function with parameters
Procedure: does a job. Function: does a job AND returns a value.

8.1.5 Nested Statements

Selection and iteration can be placed one inside another. You will never be asked for more than three levels of nesting. Identify which loop is outermost, middle and innermost before writing any code.

📘 Worked Example — 20 Students × 6 Subjects × 5 Tests
FOR Student ← 1 TO ClassSize ← outer, runs 20 times StudentHigh ← 0 : StudentTotal ← 0 FOR Subject ← 1 TO NumberOfSubjects ← middle, runs 6 times per student SubjectHigh ← 0 : SubjectTotal ← 0 FOR Test ← 1 TO NumberOfTests ← inner, runs 5 times per subject INPUT Mark NEXT Test NEXT Subject NEXT Student

Each level has its own high/low/total variables, re-initialised at the right level.

⚠️ Common Mistake — Resetting at the Wrong Level.

Resetting SubjectTotal once at the start of the program, instead of at the start of every middle-loop pass, makes the total silently carry over between subjects. No error message — just wrong answers. When tracing nested code, finish the innermost loop completely before moving on.

8.1.6 Procedures, Functions and Parameters

TermDefinition
ProcedureStatements grouped under one name, called to perform a task at any point in a program
FunctionThe same — but a function returns a value to the main program
ParameterA variable storing the value of an argument passed to a procedure or function
PROCEDURE Stars OUTPUT "************" ENDPROCEDURE CALL Stars
💡 Syllabus Update — Three Parameters, Not Two.

The older textbook says two parameters. The 2026–2028 syllabus allows up to three. This is confirmed by the June 2025 examiner report, which awarded full marks to everyone on Q10 because the question needed three parameters while the then-current syllabus said two. Follow the current syllabus: three.

ScopeMeaning
Global variableUsable by any part of the program — scope is the whole program
Local variableUsable only inside the part (e.g. the procedure) it was declared in
📘 Worked Example — Tracing Scope

Answer is declared both globally and locally inside procedure Test. Inside the procedure, Answer becomes 30 — but that is the local one. Back in the main program, the global Answer is still 150, untouched.

Number3 is declared only inside Test, so OUTPUT Number3 in the main program is an error — its scope never reached outside the procedure.

⚠️ Exam Tip.

To decide local or global, look at where it was declared — not at how important the variable looks. And when writing a CALL, pass the right number of arguments, in the right order, matching the definition exactly.

8.1.7 Library Routines

RoutineReturnsExample
MODThe remainder of a divisionMOD(10,3) → 1

ROUNDA value rounded to N decimal placesROUND(6.97354, 2) → 6.97

📘 Real Exam Question — Paper 22 Q5(b) [2]

"Write the pseudocode statement that will output the average height rounded to one decimal place."

OUTPUT ROUND(Total / 500, 1)

One mark for the average calculation, one for the correct use of ROUND with the decimal places set to 1 — inside the OUTPUT statement, not applied afterwards.

⚠️ Examiner Evidence.

Paper 21: "Most candidates were able to identify the correct purpose of MOD and DIV with only a few giving the correct pseudocode for MOD and DIV." Knowing what they do is not enough — practise writing MOD(a,b) and DIV(a,b).

8.1.8 Creating a Maintainable Program

FeatureIn practice
Meaningful identifiersEvery variable, constant, array, procedure and function named after what it represents
Division into modulesSplit into procedures and functions, one per task, not one long block
Full commentingComments explaining what each section does, using the language's own comment syntax
📘 Worked Example — Same Code, Maintainable
Poor: Improved: DECLARE X : REAL // area of a circle from its radius DECLARE Y : REAL DECLARE Radius, Area : REAL X ← Y * 3.142 * Y CONSTANT PI = 3.142 Area ← Radius * PI * Radius
💡 Exam Tip — Name It, Then Show It.

If asked for "a method to make the algorithm maintainable", do not just name the feature — give an example applied to the algorithm in the question. That is what separates full from partial marks. Note that exam questions may deliberately show badly named code to test your debugging; code you write should always follow the rules.

8.2 Arrays

lists of data
One- and two-dimensional arrays
Array indexes usually start at 0 (or as stated in the question).

8.2.1 One- and Two-Dimensional Arrays

An array is a data structure holding several elements of the same data type, all under one identifier, each reached by its index.

DECLARE MyList : ARRAY[0:9] OF INTEGER ← a 1D list, 10 elements DECLARE MyTable : ARRAY[0:9,0:2] OF INTEGER ← a 2D table, 10 rows × 3 columns MyList[4] ← 27 stores 27 at index 4 OUTPUT MyTable[2,1] row 2, column 1
⚠️ Common Mistakes.
  • Which index is which. Read the declaration: ARRAY[first row : last row, first column : last column]. Never assume.
  • First index. It may be 0 or 1 depending on the language — most languages start at 0. Check before writing loop bounds.
  • Parallel arrays. Where Names[] and Heights[] hold related data, use the same loop variable as the index into both. Using Index in one place and Counter in another is a documented real exam error (Paper 22 Q5, line 11).

8.2.2 Filling Arrays With Iteration

FOR Counter ← 0 TO 9 OUTPUT "Enter next value " INPUT MyList[Counter] ← the loop VARIABLE is the index NEXT Counter FOR ColumnCounter ← 0 TO 2 ← 2D needs NESTED loops FOR RowCounter ← 0 TO 9 INPUT MyTable[RowCounter, ColumnCounter] NEXT RowCounter NEXT ColumnCounter
⚠️ Loop-Index Matching Rule.

The order of the indexes inside the array reference must match the order in the declaration (rows then columns). Swap them and the data goes silently into the wrong cells — with no error message.

📘 Real Exam Question — Paper 22 Q4(b), double entry verification [6]
FOR Index ← 1 TO 10 INPUT Numbers[Index] NEXT Index FOR Index ← 1 TO 10 INPUT CheckNumber IF CheckNumber <> Numbers[Index] THEN OUTPUT CheckNumber, " and ", Numbers[Index], " do not match. Please re-enter. " INPUT Numbers[Index] ENDIF NEXT Index OUTPUT "The check has been completed."

Marks for: a working loop · first inputs stored in the array · a second input per number · a selection comparing them · an output showing both values and asking for a re-input · the new input stored back in the same array position.

File handling

8.3 File Handling

Data in RAM is volatile — lost when the power goes. Data in a file is permanent. That contrast is the answer to "why store data in a file", and it gives three uses:

  • Persistence — the same program can read it back on a later run.
  • Sharing — another program can use it.
  • Transfer — it can be sent to other computers.
OPEN MyFile FOR WRITE WRITEFILE MyFile, TextLine CLOSEFILE(MyFile) OPEN MyFile FOR READ ← re-open in the other mode to switch READFILE MyFile, TextLine OUTPUT TextLine CLOSEFILE(MyFile)
⚠️ Open–Use–Close Rule.

A file must be opened in the correct mode before use and closed as soon as you are finished. Forgetting to close it, or closing it too early, are both genuine documented errors — an open file can block later access, and an early close causes data loss. Show the full open → read/write → close sequence, and use the syllabus keywords (OPEN … FOR READ, WRITEFILE, READFILE, CLOSEFILE), not a specific language's syntax.

🔑 Key terms

Variable / constant
A named memory location whose value can change (variable) or stays fixed (constant).
Data types
integer, real, char, string and Boolean.
Sequence
Statements executed one after another in order.
Selection
Choosing which statements to run using IF or CASE statements.
Iteration
Repeating statements: count-controlled, pre-condition or post-condition loops.
Totalling and counting
Keeping a running total, or a count, as a program loops.
String handling
Operations on text: length, substring, upper and lower.
Operators
Arithmetic (+ - * / ^ MOD DIV), relational (= < <= > >= <>) and logical (AND, OR, NOT).
Nested statements
A selection or iteration placed inside another; no more than three levels are required.
Procedure / function
A named subroutine; a function returns a value, a procedure does not. Both may take up to three parameters.
Local / global variable
A local variable exists only inside its subroutine; a global variable can be used throughout the program.
Library routine
A ready-made subroutine such as MOD, DIV, ROUND or RANDOM.
Maintainable program
One that uses meaningful identifiers, comments, and procedures and functions so it is easy to understand and change.
Array (1D / 2D)
A data structure holding several items of the same type under one name, accessed by an index.
File handling
Opening, reading or writing (a single item or a line of text) and closing a file so data is stored outside the program.
