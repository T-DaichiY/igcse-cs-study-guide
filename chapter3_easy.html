3.1 The CPU, simply

What the CPU does, how it fetches and runs instructions, and what "embedded system" means

The CPU (central processing unit) is the chip that actually runs your programs. It's sometimes called a microprocessor. Without it, nothing on the computer would work at all.

🍎 In plain words

Don't just say the CPU is "the brain" — say what it actually does: it processes/executes instructions and data. That's the exact phrase examiners look for.

Part of the CPUWhat it does
Control unit (CU)Bosses the CPU around — sends signals telling other parts what to do
Arithmetic and logic unit (ALU)Does the maths (+, −) and logic (AND, OR)
RegistersTiny, super-fast storage spots inside the CPU

How the CPU actually runs an instruction

Every single instruction goes through three steps, over and over, thousands of times a second — this is the fetch–decode–execute cycle:

🧮 Fetch, decode, execute
1Fetch: grab the next instruction from memory.
2Decode: work out what the instruction actually means.
3Execute: actually do it.
➜ Then it goes back to step 1 and fetches the next instruction — non-stop, all the time the computer is on.
🍎 In plain words

It's like reading a recipe one line at a time: read the line (fetch), work out what it means (decode), then actually do it (execute) — then move to the next line.

What makes a CPU fast

⏱️
Clock speed
How many times per second the CPU "ticks". Faster clock = faster processing, but pushing it too far (overclocking) can cause overheating and crashes.
📦
Cache
A small, super-fast storage area inside the CPU holding things it uses often, so it doesn't have to fetch them from slower memory every time.
🧩
Number of cores
More cores can work on more things at once — but doubling the cores does NOT double the speed, because the cores have to talk to each other.
⚠️ Watch out: "clock" and "clock speed" are not the same thing. The clock is the actual part; clock speed is just a number describing how fast it ticks. Real students lost marks in 2025 for mixing these up.

Instruction set

A CPU can only understand a fixed, limited list of commands — this list is called the instruction set. It's written in low-level machine code, not a normal programming language like Python.

Embedded systems

An embedded system is hardware + software built to do just one job — unlike a computer, which can run all sorts of different programs.

🍎 In plain words

A washing machine's controller only ever does one thing: run wash cycles. A laptop can do anything depending on what software you install. That's the key difference between an embedded system and a general-purpose computer.

⚠️ If asked "why isn't a computer an embedded system?", don't just say "it does more than one job" — also give a second reason, like: its hardware isn't dedicated to one task, or its software is easy to update. Giving only one reason loses marks.

3.2 Getting data in and out

Input devices, output devices, and sensors that read the real world

A computer needs ways to get data in (input devices), send results out (output devices), and read the physical world around it (sensors).

Input devices

📊
Barcode / QR scanner
Reads dark/light patterns with a laser or camera — fast, and no need to remember prices
📷
Digital camera
Light hits a sensor chip and gets turned into a digital picture
⌨️
Keyboard
Detects which key you pressed and looks up its character code
🖱️
Optical mouse
A tiny camera and LED track how the mouse moves — no moving parts, so it's reliable
⚠️ A digital camera is an input device (it captures new data) — not a storage device, even though it can also hold photos. Lots of real students got this wrong in 2025!

Output devices

DeviceBest used for
Inkjet printerA few good-quality colour photos
Laser printerA big batch of documents, fast and cheap per page
3D printerBuilding a solid object, layer by layer
SpeakerTurning digital sound back into something you can hear
🍎 Watch out

A TV labelled "LED" might actually be an LCD screen that's just lit up by LEDs from behind — a true LED screen has each pixel as its own tiny light. These are not quite the same thing!

Sensors — the computer's senses

Sensors measure something in the real world (temperature, light, pressure...) and send that reading to the computer. The real world is analogue (smoothly changing), so an ADC (analogue-to-digital converter) turns it into digital numbers the computer can use.

SensorGood example use
TemperatureCentral heating switching on/off
LightStreet lights turning on at night
Passive infra-redDetecting a person's body heat for a security alarm
PressureWeighing a lorry as it drives over a sensor
🍎 In plain words

Pick the sensor that matches exactly what's being measured. "Detect body heat" means passive infra-red — not just any motion or infra-red sensor. Similar-sounding sensors often measure different things (like moisture vs humidity)!

3.3 Where data lives

RAM, ROM, hard disks, SSDs, virtual memory and cloud storage — in plain terms

RAM and ROM — memory the CPU can reach directly

🍎 In plain words

RAM is like a desk — you can put things on it and take them off, but when you leave (power off), the desk gets cleared. ROM is like words engraved in stone — permanent, and can't be changed, even when the power is off.

RAMROM
Can you change it?YesNo — read only
Loses data when off?Yes (volatile)No (non-volatile)
Used forPrograms currently runningStart-up instructions
⚠️ If a question already says "RAM" as one example of primary storage and asks for another, don't repeat RAM! Say ROM, cache, or a register instead.

Secondary storage — the permanent stuff

RAM is too small and clears itself, so we need secondary storage to keep files, apps and the operating system permanently, even with the power off. Secondary storage is not directly reachable by the CPU (unlike RAM/ROM) and is always non-volatile.

💽
Magnetic (HDD)
Spinning disks with a magnetic surface, read by a moving arm — like a tiny record player
💿
Optical (CD/DVD/Blu-ray)
A laser reads tiny bumps and flat spots on a spinning disc
🔌
Solid-state (SSD/USB)
No moving parts at all — data stored in tiny electronic switches, so it's fast and tough
🍎 In plain words

Don't just say a hard drive "has moving parts" — say what moves: spinning platters and a read-write head, organised in tracks and sectors. That's the detail examiners actually want.

Virtual memory — borrowing space from the hard disk

If too many programs need RAM at once, the computer could crash. Virtual memory fixes this by using part of the hard disk/SSD as "extra RAM" — data is swapped back and forth as needed.

🍎 In plain words

It's like a small desk (RAM) with a filing cabinet nearby (the hard disk). If the desk is full, you put the oldest paperwork in the cabinet to make room for what you need right now. This gives the illusion that you have way more desk space than you really do.

⚠️ Saying "secondary storage is partitioned" only earns the first, easiest mark. To get full marks, also explain that data is actively swapped between RAM and the disk as programs compete for space.

Cloud storage

Your data is stored on someone else's servers, somewhere else, and you reach it over the internet.

🍎 In plain words

Cloud storage isn't magic with no hardware — it still lives on real, physical servers owned by a company. The trade-off is: you can get your files from anywhere, but you also hand over control of where and how your data is kept safe.

3.4 Getting online

NIC, MAC address, IP address and routers — how a device actually connects to a network

To connect to the internet, a device needs a few pieces working together.

🍎 In plain words

Think of it like sending a letter: the NIC is your letterbox, the MAC address is your house's permanent name plaque, the IP address is your changeable postal address, and the router is the local post office sorting where things go.

Network interface card (NIC)

A device needs a NIC to be able to connect to a network at all. It holds the device's MAC address, set at the factory.

MAC address — your device's permanent name tag

A MAC address is a 48-bit code, written as six pairs of hex digits, e.g. 00-1C-B3-4F-25-FF. The first half identifies the manufacturer; the second half is the device's own serial number. It's set once, at the factory, and (usually) never changes.

IP address — your device's current location online

TypeMeaning
Static IPNever changes — good for servers/websites
Dynamic IPCan change each time you connect — used for most home devices
🍎 In plain words

MAC address = who the device physically is (never changes). IP address = where it is on the internet right now (can change). Don't mix these two up!

Router — the traffic director

A router connects your home network to the wider internet. It has three jobs: sends data to the right destination between networks, can hand out (private) IP addresses to your devices, and connects your home network (LAN) to the internet (WAN).

⚠️ If asked to describe a router's role, give all three jobs, not just one — exam mark schemes usually give one mark for each separate point.

🔑 Key words

CPU
The chip that processes/executes all instructions and data.
Fetch-decode-execute
The cycle every instruction goes through: get it, work it out, do it.
Cache
Super-fast memory inside the CPU for frequently-used data.
Embedded system
Hardware + software built for just one dedicated job.
Sensor
Measures something in the real world (light, heat, pressure...).
RAM / ROM
Changeable, temporary memory / permanent, read-only memory.
Secondary storage
Permanent storage the CPU can't reach directly (HDD/SSD/DVD).
Virtual memory
Using part of the hard disk as "extra RAM" when RAM is full.
MAC address
A device's permanent, factory-set hardware address.
IP address
A device's current address on the internet — static or dynamic.
Router
Connects your home network to the internet and directs data.
