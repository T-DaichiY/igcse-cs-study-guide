5.1 The Internet and the Web

How web pages are found, addressed, and remembered

People often say "the internet" and "the web" as if they're the same thing — they aren't. The internet is the huge worldwide network of wires, cables and devices that connects computers together. The World Wide Web is just one thing that runs on top of that network — the collection of websites and pages you view with a browser.

🍎 In plain words

The internet is like the road network of a country — it lets things travel between places. The World Wide Web is like the shops and houses you can visit using those roads. The roads (internet) can also be used for other things too, like the postal service (email).

Web addresses — URLs

A URL is just a text address for a web page, like a street address for a website. It's built from a protocol (http/https), a domain name (the site's name), and a file name (the specific page).

🧮 Breaking down a URL
1Take https://www.hoddereducation.co.uk/ict.
2Protocol: https. Domain name: hoddereducation.
3File name/path: ict.
➜ Protocol, domain name, file name — the three parts examiners want you to name.

HTTP and HTTPS

HTTP is the set of rules used to send web pages across the internet. HTTPS is the same thing but with a lock added — extra security (encryption) so nobody else can read the data as it travels. Look for the little padlock in your browser to know it's https.

🍎 In plain words

HTTP is like sending a postcard — anyone who handles it along the way could read it. HTTPS is like sending a sealed, locked envelope — only the sender and the intended reader can see what's inside.

Web browsers

A web browser is the software (like Chrome or Safari) that shows you web pages, by translating the HTML code sent from a website into the page you see. Browsers also do lots of other jobs.

⭐
Bookmarks
Save your favourite pages
🕓
History
Remembers sites you visited
🗂️
Tabs
Have many pages open at once
🍪
Cookies
Remembers things about you

How a web page is found — DNS

Every website lives on a computer called a web server, and every web server has a number called an IP address. But typing numbers would be a pain, so we type a URL instead — and a DNS server looks up which IP address matches that URL.

🍎 In plain words

Think of DNS like a phone book. You don't remember your friend's phone number by heart — you look up their name, and the phone book tells you the number to dial. DNS looks up a website's name and tells your computer its "number" (IP address).

🧮 Steps to load a page
1You type a URL — your browser asks DNS for its IP address.
2DNS finds the IP address and sends it back.
3Your computer contacts the web server directly using that IP address and asks for the page.
➜ The web server sends back the HTML, and your browser displays it.

Cookies

Cookies are tiny text files a website leaves on your computer so it can remember you next time — like your language, or what's in your shopping basket.

Session cookiePersistent cookie
Disappears when you close the browserStays until it expires or you delete it
Kept in temporary memorySaved on the hard drive
🍎 In plain words

A session cookie is like a sticky note you throw away when you leave the room. A persistent cookie is like a note pinned to the wall that stays there until someone takes it down.

5.2 Digital Currency

Money that only exists on a computer, and how blockchain keeps it safe

Digital currency is money that only exists as data — you can't hold it in your hand like coins or notes (called fiat currency). Apps like PayPal or Apple Pay let you use it to pay for things.

🍎 In plain words

It's like the difference between a paper gift voucher and a number in an app that says how much credit you have. One is physical, the other only exists as data.

Cryptocurrency — money with no "boss"

Normal digital money still goes through a bank in the middle. Cryptocurrency cuts the bank out — it lets two people send money directly to each other, kept safe by something called a blockchain instead of one central bank.

Blockchain — a chain that can't be secretly changed

A blockchain is like a shared notebook that every computer in the network has an identical copy of. Every new transaction becomes a new block, and each block is linked to the one before it using a special code (a hash).

🧮 Why you can't cheat a blockchain
1Someone tries to sneakily change an old transaction in block 2.
2That changes block 2's special code (hash).
3Block 3 was expecting block 2's old code — now it doesn't match.
➜ Everyone can instantly see something's wrong — the cheat is caught!
🍎 In plain words

Imagine a class notebook passed around, where every new page has to quote the last sentence of the page before it. If someone tears out a page and rewrites it, the next page's quote suddenly doesn't match — everyone notices instantly.

5.3 Cyber Security

Online dangers, and simple ways to stay safe

There are lots of ways cybercriminals try to steal data or cause harm online. Here are the main ones:

🔓
Brute-force
Guessing a password by trying combination after combination
🌊
DDoS attack
Loads of infected computers flood a website at once until it crashes
🎣
Phishing
A fake email tricks you into clicking a bad link — you have to click something
🚜
Pharming
You get redirected to a fake site automatically — you don't click anything
🎭
Social engineering
Tricking a person (not a computer) into giving away information
🦠
Malware
Harmful software — viruses, worms, spyware, ransomware and more
🍎 In plain words

Phishing is like someone handing you a fake letter, hoping you'll open it and fall for the trick. Pharming is sneakier — it's like someone secretly swapping the street sign so you walk into the wrong (fake) shop without even realising.

Staying safe — simple defences

DangerHow to defend against it
Weak passwords / brute-forceUse a long, complex password + two-step verification
MalwareKeep anti-malware software updated
Phishing / pharmingCheck spelling, tone and the URL before clicking; look for https/padlock
Data being interceptedUse encryption (SSL/https), avoid public Wi-Fi for sensitive tasks

Proving who you are — authentication

Websites check you are who you say you are using: something you know (a password), something you have (your phone), or something you are (a fingerprint).

🍎 In plain words

Two-step verification is like a locked door with two locks — your password opens the first lock, and a one-time code sent to your phone opens the second. Even if a thief steals your password, they still can't get in without your phone too.

How SSL keeps a connection secure

SSL locks your data so only you and the website can read it, using a "digital certificate" as proof of identity.

🧮 How the secure "handshake" works
1Your browser asks the website to prove who it is.
2The website sends back its digital certificate.
3Your browser checks the certificate is genuine.
➜ If it checks out, a locked (encrypted) connection begins.
