What each command word means

Straight from the 0478 syllabus — the command word tells you exactly what kind of answer is expected

Every exam question is built around a command word. Command words tell you what you actually have to do — not just what topic the question is about. Answering the topic correctly but ignoring the command word is one of the most common ways marks are lost.

From the June 2025 examiner report (Paper 0478/12, Key messages): "Candidates need to show a greater use of technical terminology in their responses. Candidates will also need to note the key terms given in a question and structure their responses using these. Candidates must also use the given context in their responses." — the command word and the scenario given in the question must both shape your answer.

Command wordWhat it means
CalculateWork out from given facts, figures or information.
CompareIdentify and/or comment on similarities and/or differences.
DefineGive a precise meaning.
DemonstrateShow how, or give an example.
DescribeState the points of a topic / give characteristics and main features.
EvaluateJudge or calculate the quality, importance, amount, or value of something.
ExplainSet out purposes or reasons / make relationships between things clear / say why and/or how, supported with relevant evidence.
GiveProduce an answer from a given source, or from recall/memory.
IdentifyName / select / recognise.
OutlineSet out the main points.
Show (that)Provide structured evidence that leads to a given result.
StateExpress in clear terms.
SuggestApply knowledge and understanding to situations where there are a range of valid responses, to make proposals / put forward considerations.

Rule of thumb: "Identify"/"Give"/"State" want a short, precise answer — one word, term, or sentence, no justification needed. "Describe"/"Explain" want you to build the point out with detail or reasoning. "Explain" specifically wants the why or how, not just the what.

Worked examples

The same fact, answered correctly for different command words
🧮 "Identify" vs "Describe" vs "Explain" — RAM being volatile
1Identify a feature of RAM. → "RAM is volatile."
2Describe a feature of RAM. → "RAM is volatile, meaning its contents are lost when the power is turned off."
3Explain why RAM is unsuitable for permanent storage. → "RAM is volatile, so any data stored in it is lost as soon as the computer loses power — permanent storage needs to keep data even when the power is off, so a non-volatile medium such as a hard disk must be used instead."
➜ Same fact, three different amounts of detail — matched to the command word and the number of marks available.
🧮 "Compare" — hard disk drive vs solid state drive
1A weak "Compare" answer just describes each device separately: "A HDD uses spinning magnetic platters. An SSD uses flash memory." — no comparison is actually made.
2A strong "Compare" answer states the similarity/difference directly: "An SSD has no moving parts, whereas a HDD has spinning platters and a moving read/write head, so an SSD is faster and more durable but a HDD is usually cheaper per gigabyte."
➜ "Compare" must contain a direct like-for-like comparison word (whereas, but, unlike, both…), not two separate descriptions.

Real examiner-report evidence (June 2025, Paper 0478/12, Question 3(a)): candidates were asked to give two reasons an IDE feature would be useful, but many "stated that it would be easier to read or write the program" — a reason already given in the question itself, so it scored no marks. Always re-read the question stem: if a reason is already stated there, it cannot be repeated as your own answer.

Key terms

Command word
The instruction verb in a question (e.g. Explain, Compare) that tells you exactly what kind of response is expected.
Context
The scenario given in a question — examiner reports repeatedly show that the strongest answers link back to this context rather than giving a generic answer.

📌 Exam tips

Underline the command word and the number of marks before you start writing — they tell you how much detail is needed.

If a reason or fact is already given in the question stem, it cannot be reused as your own answer to "give another…".
