10.1.1 What a Logic Gate Is

A logic gate is an electronic circuit using on/off (binary) logic: it takes one or two binary inputs (each 0 or 1) and produces a single binary output, following a fixed rule. Several gates connected together form a logic circuit. The behaviour of any gate or circuit is recorded in a truth table.

The six 0478 gates: NOT AND OR NAND NOR XOR (XOR is sometimes written EOR — Exclusive OR)
💡 Two Structural Facts to Memorise.
  • NOT is the only single-input gate. One line going in ⇒ it must be a NOT gate. All five others have exactly two inputs and one output.
  • Circuits are limited to a maximum of three inputs and one output at IGCSE.

10.1.1 The Six Symbols — and the Bubble Rule

NOT1Triangle pointing to a single small circle (bubble) on the output

OR2Curved back, pointed front — no output bubble
NAND2Same D-shaped body as AND, plus a bubble on the output
NOR2Same curved/pointed body as OR, plus a bubble on the output
XOR2OR body, plus an extra curved line in front of the two inputs — no bubble
⚠️ Common Mistake — The Missing Bubble.

The bubble (inversion circle) is what turns AND into NAND, OR into NOR, and a wire into NOT. Draw a NAND without its bubble and you have drawn an AND gate — the gate mark is lost even if the rest of the diagram is perfect. Equally, an XOR without its extra input curve is just an OR gate.

💡 Exam Tip — "As Shown on the Syllabus".

That exact phrase recurs across both June 2025 Paper 2 examiner reports. Drawings are checked directly against the syllabus diagram (Section 4), not against any textbook's house style or American ANSI shapes. Always show both inputs and the single output clearly, even when the question just says "draw the symbol" — the report specifically praises answers "with two inputs and one output".

⚠️ Common Mistake — OR vs XOR.

OR and XOR agree on three of four rows (00→0, 01→1, 10→1). They differ only on the last row: for OR, A=1,B=1 gives 1; for XOR it gives 0. Check that one row separately, every time.

10.3 The Nine Conversion Skills

Given…→ draw a circuit→ complete a truth table→ write an expression
A problem statement✔ 3(a)(i)✔ 3(b)(i)✔ 3(c)(i)
A logic expression✔ 3(a)(ii)✔ 3(b)(ii)—
A truth table✔ 3(a)(iii)—✔ 3(c)(iii)
A logic circuit—✔ 3(b)(iii)✔ 3(c)(ii)
⚠️ Standing Rule — No Simplification.

Syllabus guidance is explicit: "Circuits must be drawn for the statement given, without simplification." Draw every gate the statement or expression implies, even if a neater circuit exists. Never reduce it with Boolean algebra first.

Skill — Circuit → Truth Table (work in stages)

Split the circuit into stages, label each intermediate value (P, Q, R…), and complete a column for each before the final output.

⚠️ Common Mistake — The Junction Dot.

Where one wire splits (often drawn with a solid black dot) and feeds two different gates, the value is unchanged — the same signal is simply used twice. Splitting a wire does not alter the binary value it carries.

Skill — Circuit → Expression, and Expression → Circuit

📘 Circuit → Expression: work outward from the inputs

Gate 1 on A and B is AND → (A AND B). Gate 2 on B and C is OR → (B OR C). Gate 3 joins them with XOR:

X = (A AND B) XOR (B OR C)

If a later gate takes an original input as well as an earlier gate's output, substitute the earlier expression straight in — e.g. ((A NAND C) NOR A) OR (B AND C) for a four-gate circuit.

📘 Expression → Circuit: find the outermost operator first

Given (A XOR C) OR (NOT C NAND B): the last-applied gate is the OR.

  • Left half: an XOR gate taking A and C.
  • Right half: a NOT gate inverting C, feeding a NAND gate with B.
  • Join both halves with the final OR gate to give X.

10.3 Problem statements & exam question

a worked exam question

Skill — Truth Table → Expression

Look only at the rows where the output is 1. Each such row becomes one AND term, using NOT for every input that is 0 in that row. Then OR all the terms together.

📘 Worked Example

Output is 1 on two rows: A=0,B=1 and A=1,B=1.

Row A=0, B=1 → (NOT A AND B) Row A=1, B=1 → (A AND B) X = (NOT A AND B) OR (A AND B)

The same method scales to three inputs — each 1-row becomes a three-term AND. Check your answer by building a fresh truth table from your expression and matching every row.

Skill — Problem Statement → Expression → Circuit → Truth Table

Scan the wording for the joining words AND, OR and NOT — including their everyday forms ("either…or", "as well as", "is not") — and turn each condition into a labelled binary input first.

📘 Worked Example — A Safety Alarm

"An alarm, X, sounds if A is ON and B is OFF; or if B is ON and C is OFF." With ON = 1 and OFF = 0:

X = (A AND NOT B) OR (B AND NOT C)

Circuit: an AND gate on A and NOT B; a second AND gate on B and NOT C; a final OR gate joining the two.

⚠️ Common Mistake — Assuming 0 Means "Off".

0 is not automatically "off", "false" or "safe". Always read the parameter table in the question: some conditions are defined the opposite way round (e.g. "1: ignition key not present"). Getting this backwards inverts your whole expression.

Real Exam Question — June 2025 Paper 22 Q8 (the crane)

📘 Part (a) [2 marks]

"Draw the symbol for an XOR logic gate and complete the truth table for it." — one mark for the gate, one mark for the truth table, awarded independently. Attempt both even if unsure of one.

Examiner: "Most candidates drew the correct XOR logic gate symbol, as shown on the syllabus, with two inputs and one output, and then correctly completed its truth table for it."

📘 Part (b)(i) [2 marks] — the crane

Inputs: A 0 = operator not present, 1 = operator present. B 0 = ignition key present, 1 = ignition key not present. C 0 = operator code correct, 1 = operator code not correct.

"The crane will only move if the operator is present and either the ignition key is present or the operator code is correct."

X = A AND (NOT B OR NOT C) All of these were also accepted: X = A AND NOT (B AND C) X = A AND (B NAND C) X = A AND NOT B OR A AND NOT C

Note that B = 1 means the key is absent, so "the ignition key is present" is NOT B — this is exactly the trap from section ⑩.

💡 The Five A* Rules for This Chapter.
  • Label every condition as a binary variable, with its meaning, before writing any expression. The examiner's word for the typical answer was "partially correct" — usually one condition right, the other mis-negated.
  • Use brackets so the AND/OR grouping is unambiguous, exactly as the mark scheme does: A AND (NOT B OR NOT C).
  • Any logically equivalent form earns the mark — the mark scheme accepted four different versions above.
  • Derive the circuit from your own expression, never straight from the words. Examiner report, Paper 21: "Use of the original logic expression is recommended to answer this question."
  • Use the truth table as a check on your expression. The two parts are marked independently, so a correct table can still score even when the expression is shaky.
💡 Out of Scope.

Half adders, full adders and building circuits from NAND gates only are extension material, not on the 0478 syllabus. Do not revise them for this exam.

🔑 Key terms

Logic gate
A component that takes one or more binary inputs and produces one binary output.
NOT
Single-input gate: the output is the opposite of the input.
AND
Output is 1 only if both inputs are 1.
OR
Output is 1 if at least one input is 1.
NAND
NOT AND: output is 0 only if both inputs are 1.
NOR
NOT OR: output is 1 only if both inputs are 0.
XOR (EOR)
Exclusive OR: output is 1 only if the two inputs are different.
Truth table
Lists every possible combination of binary inputs and the output each produces.
Logic circuit
Gates connected to represent a problem; limited to three inputs and one output.
Logic expression
A written form of a circuit using gate names, e.g. X = (A AND B) OR C.
